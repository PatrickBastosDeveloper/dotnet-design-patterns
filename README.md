# .NET Design Patterns

Practical implementations of **Design Patterns using C# and .NET**, focused on real-world backend scenarios.

The goal is to understand not only how each pattern works, but also **the problem it solves, when to use it, and its trade-offs**.

## 📚 Patterns

### Creational

* [ ] Factory Method
* [ ] Abstract Factory
* [ ] Builder
* [ ] Singleton

### Structural

* [ ] Adapter
* [ ] Decorator
* [ ] Facade
* [ ] Proxy

### Behavioral

* [ ] Strategy
* [ ] Observer
* [ ] Command
* [ ] State
* [ ] Mediator

## 🧪 Approach

Each pattern is implemented as an independent example containing:

* A practical backend scenario
* Implementation in C#/.NET
* Automated tests
* Comparison with and without the pattern
* Key trade-offs and use cases

## 🛠️ Tech Stack

* C#
* .NET
* xUnit
* FluentAssertions
